About us

Robot Studio started in a school robotics club. Building and rebuilding a robot to try an idea takes a lot of time, so we made a place to try it first: build it from real LEGO parts, then drive it and code it before touching a single brick.

Everything is sized and weighed like the real parts, and motors run at their real speeds, so what works here should work on the table.

Questions or ideas? Tell us at hello@example.com.
