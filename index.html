Questions

Is it free?

Yes. Make an account and start building.

Do I need to install anything?

No. It runs in your browser on a laptop or desktop.

Will my code work on the real robot?

The Python and blocks use the SPIKE Prime 3 commands, so you can copy them onto your hub. Real robots always vary a little, so test on the table too.

Which kits does it support?

SPIKE Prime, Robot Inventor, EV3 and every Technic part in the LDraw library.
